# Инструкция по тестированию команды /reset_password

## Что было сделано

✅ **Создана новая система двухфакторной верификации сброса пароля**

### Основные изменения:

1. **Новая модель `PasswordResetVerification`**:
   - 8-значный алфавитно-цифровой код
   - Срок действия 15 минут
   - Счетчик неудачных попыток (максимум 3)
   - Привязка к конкретному пользователю и chat_id

2. **Обновлен процесс сброса пароля**:
   - Пользователь заходит на сайт и вводит телефон
   - Сайт генерирует 8-значный код верификации
   - Пользователь отправляет этот код боту через команду `/reset_password`
   - Бот проверяет соответствие chat_id и кода
   - При успешной проверке бот присылает ссылку для сброса пароля

3. **Обновлены Telegram боты**:
   - `polling_bot.py` - для локального тестирования
   - `integrated_bot.py` - для production
   - `telegram_views.py` - для webhook обработки

## Как протестировать

### 1. Запуск сайта
```bash
cd "c:\Users\user\Desktop\RV кино\Web_movie1"
python manage.py runserver
```

### 2. Запуск бота (polling режим)
```bash
cd "c:\Users\user\Desktop\RV кино\Web_movie1"
python polling_bot.py
```

### 3. Пошаговый тест:

1. **Создайте тестового пользователя** (если еще не создан):
   - Зайдите на сайт: http://127.0.0.1:8000/accounts/register/
   - Зарегистрируйтесь с телефоном, например: +79123456790

2. **Подключите Telegram** (если нужно):
   - Зайдите в профиль и нажмите "Подключить Telegram"
   - Отправьте 6-значный код боту

3. **Тест сброса пароля**:
   - Зайдите на страницу: http://127.0.0.1:8000/accounts/password-reset/
   - Введите номер телефона (+79123456790)
   - Скопируйте 8-значный код верификации
   - Откройте Telegram и найдите бота @RV_kino_auth_bot
   - Отправьте команду: `/reset_password`
   - Отправьте 8-значный код, который получили на сайте
   - Бот должен прислать ссылку для сброса пароля

### 4. Проверка ошибочных сценариев:

- **Неверный код**: Бот сообщит о неверном коде
- **Истекший код**: Бот сообщит об истечении срока действия
- **Неверный chat_id**: Бот сообщит о неверном пользователе
- **Превышение попыток**: После 3 неверных попыток бот предложит помощь специалиста

## Возможные проблемы

1. **Бот не отвечает на /reset_password**:
   - Убедитесь, что бот запущен
   - Проверьте токен в .env файле
   - Убедитесь, что вы используете правильного бота (@RV_kino_auth_bot)

2. **Сайт не создает код верификации**:
   - Проверьте, что у пользователя есть телефон в профиле
   - Убедитесь, что миграции применены: `python manage.py migrate`

3. **Бот не находит код**:
   - Убедитесь, что код вводится правильно (8 символов)
   - Проверьте, что пользователь привязан к правильному chat_id

## Логика безопасности

✅ Двухфакторная верификация (телефон + Telegram)
✅ Временные коды (15 минут)
✅ Ограничение попыток (3 раза)
✅ Привязка к конкретному chat_id
✅ Логирование всех попыток
